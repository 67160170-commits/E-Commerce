# VitaShop — เว็บขายวิตามินและอาหารเสริม

โปรเจกต์วิชา Ecommerce สัปดาห์ที่ 1: วางโครงโปรเจกต์ ออกแบบฐานข้อมูล สร้างข้อมูลตัวอย่าง และพัฒนา Product Catalog
(ค้นหา กรองหมวดหมู่ เรียงลำดับ และดูรายละเอียดสินค้า)

## เริ่มใช้งาน

ต้องมี Node.js 20.9 ขึ้นไป (แนะนำ 22 LTS)

```bash
npm install
npm run db:seed     # สร้างฐานข้อมูลที่ data/shop.db พร้อมสินค้าตัวอย่าง 16 รายการ
npm run dev         # เปิด http://localhost:3000
```

`npm run db:seed` ลบข้อมูลเดิมแล้วสร้างใหม่ทุกครั้ง ใช้รีเซ็ตข้อมูลได้เสมอ

## เทคโนโลยี

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + SQLite (better-sqlite3)

- ใช้ better-sqlite3 เขียน SQL ตรง ๆ แทน Prisma เพื่อให้ตั้งค่าง่าย และตอนทำ checkout ในสัปดาห์ที่ 2 ใช้ `db.transaction()` ตรวจและตัดสต็อกพร้อมกันได้โดยตรง
- ฟอนต์ Noto Sans Thai โฮสต์เองผ่าน `@fontsource-variable` จึงไม่มีการเรียก Google Fonts

## โครงสร้างโปรเจกต์

```
db/schema.sql                 โครงสร้างตารางทั้ง 7 ตาราง
db/seed.mjs                   สร้างฐานข้อมูลและข้อมูลตัวอย่าง
scripts/check-no-cookies.mjs  ตรวจว่าไม่มีคุกกี้/สคริปต์ภายนอก
src/lib/db.ts                 การเชื่อมต่อฐานข้อมูล (ฝั่ง server เท่านั้น)
src/lib/products.ts           คำสั่ง query: ค้นหา กรอง เรียง ดึงสินค้า
src/app/page.tsx              หน้ารายการสินค้า (ค้นหา + กรอง + เรียง)
src/app/products/[id]/        หน้ารายละเอียดสินค้า
src/components/               ProductCard, CategoryFilter, ProductImage ฯลฯ
```

การค้นหาและกรองทำงานผ่าน URL (`/?q=วิตามิน&category=1&sort=price-asc`) ฟอร์มเป็น GET ธรรมดา
จึงใช้งานได้แม้ไม่มี JavaScript และแชร์ลิงก์ผลการค้นหาได้ การค้นหาแยกเป็นคำ ๆ แล้วต้องตรงทุกคำในชื่อหรือคำอธิบาย

## ฐานข้อมูล

| ตาราง | ใช้งานเมื่อ |
|---|---|
| `categories`, `products` | สัปดาห์ที่ 1 (ใช้อยู่แล้ว) |
| `users`, `addresses` | สัปดาห์ที่ 2 สมัครสมาชิก/ที่อยู่ |
| `orders`, `order_items` | สัปดาห์ที่ 2 checkout และสัปดาห์ที่ 3 จัดการออเดอร์ |
| `consent_logs` | สัปดาห์ที่ 4 Cookie Consent Banner |

- ราคาและยอดเงินเก็บเป็นจำนวนเต็มหน่วยบาท
- `orders.shipping_address` และ `order_items.unit_price` เก็บสำเนา ณ วันสั่งซื้อ เพื่อให้ประวัติไม่เปลี่ยนเมื่อแก้ที่อยู่หรือราคาสินค้าภายหลัง
- สินค้าที่ `stock <= low_stock_threshold` แสดงป้าย "เหลือน้อย" และ `stock = 0` แสดง "สินค้าหมด"

## รูปสินค้า

สินค้าตัวอย่างยังไม่มี `image_url` จึงแสดงภาพขวด placeholder ตามสีของหมวด
ถ้าจะใช้รูปจริง (ตามขอบเขตแผนงานที่ใช้ลิงก์รูป) ให้ใส่ URL ในคอลัมน์ `image_url` ของตาราง `products`
ระบบจะใช้รูปนั้นแทนทันที แต่ถ้าเป็นลิงก์จากเว็บอื่น ผู้ให้บริการรูปจะเห็น IP ของผู้เข้าชม
ถ้าต้องการหลีกเลี่ยง ให้วางไฟล์ไว้ใน `public/products/` แล้วใช้ path เช่น `/products/vitamin-c.jpg`

## กฎเรื่องคุกกี้ (PDPA)

ตอนนี้เว็บไม่ตั้งคุกกี้และไม่โหลดสคริปต์ภายนอกใด ๆ เพื่อให้แบนเนอร์ควบคุมได้ในสัปดาห์ที่ 4

- สคริปต์ที่ตั้งคุกกี้ที่ไม่จำเป็น (analytics, marketing, ตัวฝังจากภายนอก) ต้องใส่ใน `src/components/ThirdPartyScripts.tsx` เท่านั้น
- ห้ามใส่ `<script>` ของบริการภายนอกใน `layout.tsx` หรือหน้าอื่น
- ตรวจได้ทุกครั้งก่อน commit:

```bash
npm run build && npm start        # terminal 1
npm run check:cookies             # terminal 2 (ผ่านเมื่อไม่มี Set-Cookie และไม่มีทรัพยากรภายนอก)
```

## ข้อควรระวังตอน deploy

Vercel ไม่เก็บไฟล์ที่เขียนระหว่างทำงานถาวร SQLite แบบไฟล์จึงอ่านข้อมูลสินค้าได้ แต่บันทึกออเดอร์/สต็อกไม่ได้
ก่อนสัปดาห์ที่ 5 ต้องเลือกอย่างใดอย่างหนึ่ง:

1. deploy บนบริการที่มีดิสก์ถาวร (เช่น Railway, Render, Fly.io หรือ VPS) และใช้ SQLite ต่อได้เลย
2. ย้ายไปฐานข้อมูลออนไลน์ (Turso, Neon หรือ Supabase) โดยแก้เฉพาะ `src/lib/db.ts` และคำสั่งใน `src/lib/products.ts`

## ข้อมูลตัวอย่าง

ชื่อสินค้า ราคา และคำอธิบายทั้งหมดเป็นข้อมูลสมมติเพื่อการศึกษา ถ้านำไปขายจริงต้องมีเลขทะเบียน อย.
และใช้ข้อความโฆษณาที่ไม่อ้างสรรพคุณทางการรักษา

## ขั้นถัดไป (สัปดาห์ที่ 2)

ตะกร้าสินค้า สมัครสมาชิก/เข้าสู่ระบบ (bcrypt + session) และ checkout แบบ transaction
